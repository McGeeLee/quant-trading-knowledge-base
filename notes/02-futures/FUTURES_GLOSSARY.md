# 期货术语表

不同交易所和品种的正式定义可能不同。涉及真实交易时，应以对应交易所最新合约规则为准，并在品种笔记中记录查询日期。

| 术语 | 简要说明 |
|---|---|
| 期货合约 | 约定在未来按规则买卖或结算某种标的的标准化合约。 |
| 合约代码 | 交易所用于识别品种和到期月份的代码。具体格式因市场而异。 |
| 合约乘数 | 每一合约价格单位对应的标的数量，用于计算名义价值。 |
| 最小变动价位 | 报价一次允许变动的最小价格单位，也称 tick size。 |
| 保证金 | 为履约和覆盖风险而占用的资金，不等于合约的全部名义价值。 |
| 初始保证金 | 建仓时需要满足的最低保证金要求。 |
| 维持保证金 | 持仓期间必须维持的最低保证金水平，低于要求可能需要补充资金或被强平。 |
| 杠杆 | 合约名义价值相对投入资金的放大比例，会同时放大收益和损失。 |
| 开仓 | 新增期货头寸，包括买入开多和卖出开空。 |
| 平仓 | 通过反向交易减少或结束已有头寸。部分市场还区分平今和平昨。 |
| 多头 | 价格上涨时通常获利的买入持仓。 |
| 空头 | 价格下跌时通常获利的卖出持仓。 |
| 逐日盯市 | 每个结算周期按结算价计算盈亏并调整账户权益的制度。 |
| 结算价 | 交易所按规则确定、用于结算盈亏和保证金等事项的价格。它不一定等于收盘价。 |
| 最后交易日 | 某到期合约允许交易的最后日期。 |
| 交割 | 到期后按规则完成实物转移或现金差额结算。 |
| 实物交割 | 按合约规则交付或接收符合标准的标的。 |
| 现金交割 | 按指定结算价格计算差额，不进行实物转移。 |
| 基差 | 常见定义为现货价格减期货价格；使用时必须明确公式方向。 |
| 期限结构 | 同一标的不同到期月份合约价格之间的关系。 |
| Contango | 较远期合约价格通常高于较近月合约的期限结构状态。 |
| Backwardation | 较远期合约价格通常低于较近月合约的期限结构状态。 |
| 跨期价差 | 同一品种不同到期月份合约价格之差及其交易。 |
| 展期/换月 | 平掉临近到期合约并转入更远月合约的过程。 |
| 主力合约 | 按成交量、持仓量等规则选出的当前活跃合约；定义依数据源而定。 |
| 连续合约 | 为研究长期序列而将多个到期合约拼接形成的数据序列，本身通常不可直接交易。 |
| 移仓收益 | 展期时因近远月价格差和价格变化形成的收益或成本，定义需与计算方法配套。 |
| 持仓量 | 尚未通过平仓或交割结束的合约数量。 |
| 成交量 | 指定期间成交的合约数量；单边或双边统计口径应确认。 |
| 涨跌停板 | 交易价格相对参考价在一个交易日内允许波动的限制。 |
| 强制平仓 | 账户不满足风险或规则要求时，持仓被交易服务方或交易所强制减少。 |
| 仓位限制 | 交易所、监管机构或经纪商对可持有合约数量设置的限制。 |
