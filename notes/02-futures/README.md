# 期货知识

记录期货市场特有的合约机制、交易规则、定价关系、展期处理和风险知识。

## 推荐学习顺序

1. 合约要素：标的、代码、乘数、报价单位、最小变动价位。
2. 交易机制：保证金、双向交易、开平仓、逐日盯市和涨跌停。
3. 到期机制：最后交易日、结算、交割方式和仓位限制。
4. 价格关系：现货、基差、期限结构、持有成本和跨期价差。
5. 数据处理：主力合约、连续合约、换月规则和复权方式。
6. 风险：杠杆、流动性、跳空、强平、交割和模型风险。

术语入口见 [FUTURES_GLOSSARY.md](FUTURES_GLOSSARY.md)，单个品种的交易规则可使用 [CONTRACT_SPEC_TEMPLATE.md](CONTRACT_SPEC_TEMPLATE.md) 记录。
