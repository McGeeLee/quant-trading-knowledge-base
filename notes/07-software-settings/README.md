# 软件设置知识

记录可复现的软件安装、环境配置、插件、快捷键和排错步骤。使用 [SETTING_TEMPLATE.md](SETTING_TEMPLATE.md) 可以避免遗漏版本、验证和回滚信息。

## 安全边界

- 可以记录环境变量名称，但不能记录真实值。
- 不提交 API 密钥、密码、Cookie、私钥、账户号或完整认证日志。
- 机器专属路径和设备信息尽量使用占位符。
- 可共享配置与个人私密配置分开保存。
- 修改关键配置前记录备份和回滚方法。

建议子主题：Python 环境、VS Code、Jupyter、Git/GitHub、终端、Docker、数据库和行情/交易软件。
