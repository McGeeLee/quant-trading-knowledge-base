## 笔记规则

建议一篇笔记只回答一个核心问题，并包含：

1. 用自己的话解释概念。
2. 写出必要的公式和假设。
3. 给出一个数值或代码例子。
4. 说明它在量化研究中的用途与局限。
5. 链接来源、相关代码和关联知识点。
6. 列出尚未解决的问题。

知识笔记文件名建议使用 `topic.md`；带时间属性的学习记录放在 `journal/`，实验记录放在 `research/`。例如，对数收益率知识可以写成 `01-finance/log-returns.md`，当天学习过程则写入日记。
