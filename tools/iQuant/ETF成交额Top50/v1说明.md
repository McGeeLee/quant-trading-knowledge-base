# ETF 成交额 Top50 - iQuant v1 说明

## 代码位置

本文件旁边的 `v1.py` 是 iQuant 日线扫描脚本。

## 主要行为

- 使用 `000300.SH` 作为回测驱动基准。
- 从沪深基金板块获取候选证券，并识别 ETF。
- 优先读取日线成交额，必要时尝试兼容接口和当日全推快照。
- 每个交易日输出成交额前 50 名，并保存为下一交易日可用名单。
- 不发送任何交易订单。

## 需要确认

- 不同 QMT/iQuant 版本返回的成交额单位是否一致。
- 基金板块成分和历史行情是否已经完整下载。
- 若名单用于交易，只能使用上一交易日已经完成的排名。
