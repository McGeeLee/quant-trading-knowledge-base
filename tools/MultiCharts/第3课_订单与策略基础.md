# 第 3 课：订单与策略基础

本课把指标计算连接到策略下单，重点理解信号、订单时序、持仓状态和回测设置。

## 指标、函数与信号

- 指标主要计算并显示数据，例如 `Close - Close[1]`。
- 函数是可复用的计算模块，本身不等于指标；指标和信号都可以调用函数。
- 信号根据条件产生开仓、平仓或反向交易订单。

## 历史引用与初始化

```pascal
If CurrentBar > 1 then
    Plot1(Close - Close[1], "CloseDiff")
else
    NoPlot(1);
```

- `Close[1]` 表示上一根 K 线的收盘价。
- `CurrentBar` 表示当前计算到的 K 线编号。
- `MaxBarsBack`、历史资料匹配和指标自身的历史引用会影响指标何时开始输出。
- `NoPlot(1)` 表示当前 Bar 不绘制第 1 条线，不会停止指标计算。

## 收盘判断与订单时序

```pascal
If BarStatus(1) = 2 then
    Buy ("LE-Market") next bar at market;
```

- `BarStatus(1) = 2` 表示 Data1 当前 Bar 收到完成信号，即最后一笔资料到达；它不是固定的“最后一秒”。
- 实盘无法提前知道最后一笔何时出现，只能在完成事件发生后判断。
- `next bar` 表示订单安排到下一根 Bar，市价单通常在下一根可交易时点成交。
- 盘中 `Close` 会变化，收盘后 `Close` 固定；用 Bar 完成判断可以避免同一根 K 线不断重复发单。

## 持仓状态与基础策略

```pascal
Inputs: OrderQty(1);

If BarStatus(1) = 2 then
begin
    If MarketPosition = 0 and Close > Close[1] then
        Buy ("LE-Market") OrderQty contracts next bar at market;

    If MarketPosition = 1 and Close < Close[1] then
        Sell ("LX-Market") next bar at market;
end;
```

- `MarketPosition = 0` 表示空仓，`1` 表示持有多头，`-1` 表示持有空头。
- `CurrentContracts` 可查看当前持仓数量，`EntryPrice` 可查看持仓均价。
- 这份练习策略一次只持有一手，但历史上可以反复开仓和平仓。
- `SellShort` 用于开空，`BuyToCover` 用于平空。

## 订单类型

- 市价单：优先成交，价格不确定。
- 限价单：价格达到有利方向的限价才可能成交，可能不成交。
- 止损单：价格触及触发价后转为执行订单，适合突破或止损。
- 回测中的限价、止损成交取决于数据精度和同棒路径假设，不能直接等同于实盘成交。

## 回测与模拟盘设置

- 回测报告的净利、毛利、手续费、滑价、最大回撤、胜率和交易次数应一起观察。
- 初始资金和利率是资金收益/成本假设，不等于自动开启杠杆；杠杆还要结合保证金、数量和最大持仓设置。
- 模拟盘先使用 1 手，确认交易账号、商品代码映射、委托状态和实际成交回报。
- 真回报按交易商实际成交反馈；假回报按平台模拟成交，二者结果不能混用。
- 连续合约交易前要确认图表商品到实际可交易合约的代码映射。

## 第三课完成标准

能够解释一条信号为什么产生、订单在哪根 K 线提交、何时可能成交、当前是否持仓，以及回测结果受到哪些手续费、滑价、数据精度和成交假设影响。
