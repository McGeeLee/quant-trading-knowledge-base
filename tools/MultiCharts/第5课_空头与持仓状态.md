# 第 5 课：空头与持仓状态

本课在多头策略基础上加入空头交易，理解空仓、多头和空头三种状态，以及四种基本开平仓订单。

## 完整代码

```pascal
Inputs:
    OrderQty(1);

If BarStatus(1) = 2 then
begin

    // Long Entry
    If MarketPosition = 0
       and Close > Close[1] then
        Buy ("LE-Market")
        OrderQty contracts next bar at market;

    // Short Entry
    If MarketPosition = 0
       and Close < Close[1] then
        SellShort ("SE-Market")
        OrderQty contracts next bar at market;

    // Long Exit
    If MarketPosition = 1
       and Close < Close[1] then
        Sell ("LX-Market")
        next bar at market;

    // Short Exit
    If MarketPosition = -1
       and Close > Close[1] then
        BuyToCover ("SX-Market")
        next bar at market;

end;
```

## 持仓状态

```pascal
MarketPosition = 0
```

空仓，可以开多或开空。

```pascal
MarketPosition = 1
```

持有多头，只允许执行多头平仓逻辑。

```pascal
MarketPosition = -1
```

持有空头，只允许执行空头平仓逻辑。

## 四种订单

| 代码 | 含义 |
|---|---|
| `Buy` | 买入开多或增加多头 |
| `Sell` | 卖出平多 |
| `SellShort` | 卖出开空 |
| `BuyToCover` | 买入平空 |

## 图表标记

- `LE-Market`：Long Entry，多头开仓。
- `LX-Market`：Long Exit，多头平仓。
- `SE-Market`：Short Entry，空头开仓。
- `SX-Market`：Short Exit，空头平仓。

一组开仓标记和对应的平仓标记代表一笔完整交易。历史上出现很多组标记，不代表同时持有很多仓位；`MarketPosition` 条件保证策略一次只持有一个方向的仓位。

## 订单时序

策略在当前 K 线完成时判断：

```pascal
BarStatus(1) = 2
```

订单使用：

```pascal
next bar at market
```

因此信号在当前 K 线产生，订单安排到下一根 K 线执行。实际成交价可能受到跳空、流动性和滑价影响。

## 实际运行结果

在 5 分钟图运行后，应能看到 `LE-Market`、`LX-Market`、`SE-Market` 和 `SX-Market`。左侧持仓栏会显示当前是空仓、多头还是空头。

## 练习检查

1. 上涨信号是否产生 `LE-Market`？
2. 下跌信号是否产生 `SE-Market`？
3. 多头反向时是否产生 `LX-Market`？
4. 空头反向时是否产生 `SX-Market`？
5. 是否始终一次只持有一个方向的仓位？

## 完成标准

能够解释多空开仓和平仓的区别，读懂四种订单标记，并根据 `MarketPosition` 判断策略当前允许执行哪类订单。
