# 专题：神奇九转基础信号

本专题的唯一基准代码是下面这份基础九转信号。它已经在当前图表中成功运行，图上标记与代码一致：

- `LE-TD9`: Buy Setup 9 后开多
- `LX-TD9`: Sell Setup 9 后平多
- `SE-TD9`: Sell Setup 9 后开空
- `SX-TD9`: Buy Setup 9 后平空

## 完整 PowerLanguage 信号代码

```pascal
Inputs:
    OrderQty(1);

Vars:
    BuyCount(0),
    SellCount(0);

If CurrentBar <= 4 then
begin
    BuyCount = 0;
    SellCount = 0;
end
else
begin
    // Buy Setup Count
    If Close < Close[4] then
        BuyCount = BuyCount + 1
    else
        BuyCount = 0;

    // Sell Setup Count
    If Close > Close[4] then
        SellCount = SellCount + 1
    else
        SellCount = 0;
end;

If BarStatus(1) = 2 then
begin
    // Long Entry after Buy Setup 9
    If MarketPosition = 0
       and BuyCount = 9 then
        Buy ("LE-TD9")
        OrderQty contracts next bar at market;

    // Short Entry after Sell Setup 9
    If MarketPosition = 0
       and SellCount = 9 then
        SellShort ("SE-TD9")
        OrderQty contracts next bar at market;

    // Long Exit after Sell Setup 9
    If MarketPosition = 1
       and SellCount = 9 then
        Sell ("LX-TD9")
        next bar at market;

    // Short Exit after Buy Setup 9
    If MarketPosition = -1
       and BuyCount = 9 then
        BuyToCover ("SX-TD9")
        next bar at market;
end;
```
