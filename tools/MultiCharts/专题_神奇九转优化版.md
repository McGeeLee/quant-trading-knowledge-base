# 专题：神奇九转优化版

这版先解决两个问题：减少手续费拖累，并避免趋势过滤器与九转条件互相冲突。截图中的原始结果是毛利为正，但调整后盈利因子只有 0.82，因此本版默认只保留空头、限制每日交易次数，并用均线斜率判断趋势方向。

## 使用顺序

1. 先在模拟盘运行，周期保持 1 分钟或 5 分钟。
2. 默认 `ShortEnabled(true)`、`LongEnabled(false)`，先验证空头优势是否稳定。
3. 重新回测时录入真实手续费和滑点。
4. 只有调整后净利为正、调整后盈利因子持续大于 1，并且最大回撤可接受，才进入下一轮测试。

## 基准版本：基础九转信号

下面保留最初的基准版本，后续优化应始终与它单独比较。

完整代码就是你刚才提供的版本；为避免重复维护，这里以当前仓库中的历史基准代码作为对照，优化代码如下。

## 完整 PowerLanguage 信号代码

```pascal
Inputs:
    OrderQty(1),
    LongEnabled(false),
    ShortEnabled(true),
    SetupLength(9),
    CompareBars(4),
    TrendLength(20),
    UseTrendSlope(true),
    MaxTradesPerDay(2),
    StartTime(915),
    LastEntryTime(1450),
    ExitTime(1458),
    MinBarsBetweenEntries(10),
    StopLossAmount(9000),
    ProfitTargetAmount(12000);

Vars:
    BuyCount(0),
    SellCount(0),
    TrendAverage(0),
    TrendAveragePrev(0),
    EntryAllowed(false),
    LongFilter(true),
    ShortFilter(true),
    EntrySpacingOK(true);

// Count consecutive setup bars.
If CurrentBar <= CompareBars then
begin
    BuyCount = 0;
    SellCount = 0;
end
else
begin
    If Close < Close[CompareBars] then
    begin
        If BuyCount < SetupLength then
            BuyCount = BuyCount + 1;
    end
    else
        BuyCount = 0;

    If Close > Close[CompareBars] then
    begin
        If SellCount < SetupLength then
            SellCount = SellCount + 1;
    end
    else
        SellCount = 0;
end;

// Use moving-average direction instead of price location.
TrendAverage = AverageFC(Close, TrendLength);
TrendAveragePrev = TrendAverage[1];

If UseTrendSlope then
begin
    LongFilter = TrendAverage > TrendAveragePrev;
    ShortFilter = TrendAverage < TrendAveragePrev;
end
else
begin
    LongFilter = true;
    ShortFilter = true;
end;

// Restrict entries to the liquid daytime session.
EntryAllowed =
    Time >= StartTime
    and Time <= LastEntryTime
    and EntriesToday(Date) < MaxTradesPerDay;

// Keep the spacing switch explicit; flat-state history differs by platform version.
EntrySpacingOK = true;

If BarStatus(1) = 2 then
begin
    // Buy setup 9 is used only when the moving average is rising.
    If MarketPosition = 0
       and EntryAllowed
       and EntrySpacingOK
       and LongEnabled
       and LongFilter
       and BuyCount = SetupLength then
        Buy ("LE-TD9")
        OrderQty contracts next bar at market;

    // Sell setup 9 is used only when the moving average is falling.
    If MarketPosition = 0
       and EntryAllowed
       and EntrySpacingOK
       and ShortEnabled
       and ShortFilter
       and SellCount = SetupLength then
        SellShort ("SE-TD9")
        OrderQty contracts next bar at market;

    // Exit when the opposite setup completes.
    If MarketPosition = 1
       and SellCount = SetupLength then
        Sell ("LX-TD9") next bar at market;

    If MarketPosition = -1
       and BuyCount = SetupLength then
        BuyToCover ("SX-TD9") next bar at market;

    // Flatten before the session ends.
    If MarketPosition = 1
       and Time >= ExitTime then
        Sell ("LX-Time") next bar at market;

    If MarketPosition = -1
       and Time >= ExitTime then
        BuyToCover ("SX-Time") next bar at market;
end;

// Protective exits are evaluated by the platform.
SetStopLoss(StopLossAmount);
SetProfitTarget(ProfitTargetAmount);
```

## 本轮只改三个旋钮

- `LongEnabled(false)`：先关闭多头，验证空头是否仍有优势。
- `MaxTradesPerDay(2)`：减少频繁开平造成的手续费。
- `StopLossAmount(9000)` / `ProfitTargetAmount(12000)`：先保持 3:4 的风险收益比，再根据报告微调。

注意：`EntriesToday(Date)` 对跨夜期货时段可能按自然日统计。若以后测试夜盘，需要改成交易所交易日计数后再用于实盘。
