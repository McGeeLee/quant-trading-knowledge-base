# 第 4 课：最小可用策略

本课把一个简单的价格条件转换成完整的多头策略，完成“信号、开仓、持仓、平仓”的最小循环。

## 学习目标

- 区分指标和信号。
- 使用 `MarketPosition` 判断当前持仓状态。
- 使用 `BarStatus(1) = 2` 在当前 K 线完成时判断。
- 使用 `next bar at market` 安排下一根 K 线的市价订单。
- 根据交易标记检查策略是否按代码运行。

## 完整代码

```pascal
Inputs:
    OrderQty(1);

If BarStatus(1) = 2 then
begin

    // 空仓，当前收盘价高于上一根收盘价：下一根做多
    If MarketPosition = 0
       and Close > Close[1] then
        Buy ("LE-Market")
        OrderQty contracts next bar at market;

    // 持有多单，当前收盘价低于上一根收盘价：下一根平仓
    If MarketPosition = 1
       and Close < Close[1] then
        Sell ("LX-Market")
        next bar at market;

end;
```

## 代码说明

```pascal
Inputs:
    OrderQty(1);
```

定义委托数量，默认交易 1 手。正规期货通常只能按整数手交易。

```pascal
BarStatus(1) = 2
```

表示 Data1 当前 K 线完成，策略在完成时判断一次，避免同一根 K 线反复发出相同信号。

```pascal
MarketPosition = 0
```

表示空仓，只有空仓时才允许开多。

```pascal
MarketPosition = 1
```

表示持有多头，只有持有多头时才允许平仓。

```pascal
Close > Close[1]
```

当前 K 线收盘价高于上一根 K 线收盘价，产生多头开仓信号。

```pascal
Buy ("LE-Market") OrderQty contracts next bar at market;
```

下一根 K 线用市价买入。`LE` 是 Long Entry 的缩写。

```pascal
Sell ("LX-Market") next bar at market;
```

下一根 K 线用市价平掉多头。`LX` 是 Long Exit 的缩写。

## 图表标记

- `LE-Market`：多头开仓。
- `LX-Market`：多头平仓。
- 一组 LE 和 LX 代表一笔完整交易。
- 历史上有很多组标记，不表示同时持有很多仓位。
- 右侧显示“持仓 0”表示当前没有未平仓头寸。

## 第四课实际结果

在 5 分钟图运行后，策略能够反复产生 `LE-Market` 和 `LX-Market` 标记。由于条件只比较相邻两根收盘价，价格方向频繁变化时交易标记会比较密集，这是代码逻辑的直接结果。

本课没有加入止损、止盈、空头或均线过滤，目的是先验证最小策略循环。

## 练习检查

1. 是否出现 `LE-Market`？
2. 每次开仓后是否出现对应的 `LX-Market`？
3. 持仓期间是否重复开仓？
4. `next bar` 是否按下一根 K 线执行？
5. 左侧持仓状态是否与图表标记一致？

## 完成标准

能够说明一笔交易从条件成立到订单成交、持仓建立、条件反向到平仓的完整过程，并能从图上的 LE/LX 标记验证代码逻辑。
