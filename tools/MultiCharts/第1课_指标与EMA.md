# 第 1 课笔记：指标执行、CurrentBar 与 EMA 初始化

## 1. 当前学习对象

图表品种是沪深 300 期货主力连续，当前使用日线图。图表上的 `Mov Avg Exp Ribbon` 是指标，不是自动交易策略。

当前参数：

```text
Price = Close
BaseLength = 10
ArithOrGeom_1or2 = 1
IncrementOrMultiplier = 10
```

因此 8 条均线的周期为：

```text
10、20、30、40、50、60、70、80
```

`BaseLength` 表示起始的 K 线根数，不是固定的“天数”。在日线图上可以近似理解为交易日数；切换到分钟图后，它表示分钟 K 线的根数。

## 2. 初始化代码

第一根正式计算柱执行：

```pascal
if CurrentBar = 1 then
begin
    arr0[1] = BaseLength;
    arr1[1] = 2 / (arr0[1] + 1);
    arr2[1] = Price;
    arr3[1] = GradientColor(1, 1, 8, FastColor, SlowColor);
    { 循环建立第 2 到第 8 条线 }
end;
```

第一次循环的作用是建立 8 条线的参数和初始值：

- `arr0`：均线周期。
- `arr1`：EMA 平滑系数 Alpha。
- `arr2`：均线当前值。
- `arr3`：均线颜色。

当 `var0 = 7` 时，循环正在建立第 8 条线，即 `arr0[8]`、`arr1[8]`、`arr2[8]` 和 `arr3[8]`。这不是第 7 根 K 线。

第一根正式计算柱中，8 条均线都会执行：

```pascal
arr2[1] = Price;
arr2[2] = Price;
...
arr2[8] = Price;
```

因此它们最开始会重叠在同一个价格点。

## 3. 后续 EMA 更新

后续 K 线执行：

```pascal
for var0 = 1 to 8
begin
    arr2[var0] = arr2[var0][1]
        + arr1[var0] * (Price - arr2[var0][1]);
end;
```

这就是 EMA 递推公式：

```text
当前 EMA = 上一根 EMA + Alpha × (当前价格 - 上一根 EMA)
```

周期越短，Alpha 越大，均线反应越快；周期越长，Alpha 越小，均线越平滑但滞后越明显。

## 4. Plot 的执行顺序

代码最后的 8 个 `Plot`：

```pascal
Plot1(arr2[1], "XMA1", arr3[1]);
...
Plot8(arr2[8], "XMA8", arr3[8]);
```

在指标进入正式计算后，每根 K 线都会执行这些 Plot。它们不是等到 `CurrentBar = 7` 才由代码触发。

但 MultiCharts 会先根据指标的历史引用和 `MaxBarsBack` 确定起算点。当前实验中，图表前面有几根 K 线没有显示均线，第一组可见结果出现在数据窗口 `CB = 7` 附近。

因此要区分：

```text
代码逻辑：正式计算后每根 K 线都执行 Plot
平台行为：先准备 MaxBarsBack / 回溯数据，再进入正式计算起点
```

当前代码没有写 `if CurrentBar >= 7`；这个 7 来自当前图表的计算起点或回溯设置，不能直接从 Plot 语句本身推导出来。

## 5. 实验结论

临时增加：

```pascal
Plot9(CurrentBar, "CB");
```

可以观察指标实际开始绘制的位置。实验显示，当前图表的第一组可见均线和 `CB = 7` 对应。

这验证了：

1. 第一组可见均线出现时，`arr2` 和 `arr3` 已经有值。
2. `Plot1` 到 `Plot8` 在正式计算阶段正常执行。
3. 图表最左侧没有线，主要与平台的起算点/回溯设置有关，而不是因为代码把 8 条线分开计算后才绘图。

## 6. 初始化误差

虽然程序可以在早期 K 线产生 EMA 数值，但这不等于均线已经稳定。因为所有均线都从第一根价格初始化：

```text
能产生数值 ≠ 已经得到稳定的 N 周期 EMA
```

要减少启动误差，可以：

1. 加载更多历史 K 线作为预热数据。
2. 用前 N 根价格的简单平均初始化 EMA。
3. 使用平台内置的 `XAverage` 函数。

如果最长周期是 80，正式分析时不应只依赖最初几十根 K 线。

## 7. 当前结论

这段程序的流程是：

```text
平台准备回溯数据
→ 指标进入正式计算起点
→ 建立 8 条均线参数和初始值
→ 执行 Plot1 到 Plot8
→ 后续每根 K 线更新 EMA 并重新绘图
```

均线是价格经过平滑计算后的结果。价格是输入，EMA 是递推结果，滞后是平滑带来的代价。
