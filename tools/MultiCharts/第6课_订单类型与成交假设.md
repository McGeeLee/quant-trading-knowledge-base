# 第 6 课：订单类型与成交假设

本课比较市价单、限价单和止损单，并理解回测与实盘成交的差异。

## 完整代码

```pascal
Inputs:
    OrderQty(1),
    OrderMode(1);

If BarStatus(1) = 2 then
begin

    // Long Entry
    If MarketPosition = 0
       and Close > Close[1] then
    begin

        If OrderMode = 1 then
            Buy ("LE-Market")
            OrderQty contracts next bar at market;

        If OrderMode = 2 then
            Buy ("LE-Limit")
            OrderQty contracts next bar at Low limit;

        If OrderMode = 3 then
            Buy ("LE-Stop")
            OrderQty contracts next bar at High stop;

    end;


    // Short Entry
    If MarketPosition = 0
       and Close < Close[1] then
    begin

        If OrderMode = 1 then
            SellShort ("SE-Market")
            OrderQty contracts next bar at market;

        If OrderMode = 2 then
            SellShort ("SE-Limit")
            OrderQty contracts next bar at High limit;

        If OrderMode = 3 then
            SellShort ("SE-Stop")
            OrderQty contracts next bar at Low stop;

    end;


    // Long Exit
    If MarketPosition = 1
       and Close < Close[1] then
        Sell ("LX-Market")
        next bar at market;


    // Short Exit
    If MarketPosition = -1
       and Close > Close[1] then
        BuyToCover ("SX-Market")
        next bar at market;

end;
```

## 参数

```text
OrderMode = 1：Market
OrderMode = 2：Limit
OrderMode = 3：Stop
```

### Market

优先成交，但成交价格不确定，实盘可能有滑点。

### Limit

价格达到有利方向的限价才可能成交。回测通常按“触及即成交”处理，实盘还会受到排队和流动性影响。

### Stop

价格突破触发价后执行。快速行情中可能跳价，实际成交价可能比触发价差。

## 回测与实盘差异

- 回测无法完整模拟排队、网络延迟和盘口深度。
- 同一根 K 线中同时触及多个价格时，OHLC 数据无法确定真实先后顺序。
- 5 分钟和日线的成交顺序假设比 1 分钟或逐笔资料更粗略。
- 市价单、限价单和止损单都需要用模拟盘验证实际成交回报。

## 完成标准

能够通过 `OrderMode` 切换三种开仓方式，解释订单为什么成交或没有成交，并知道回测标记不能完全代表实盘成交。
