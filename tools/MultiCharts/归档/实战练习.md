# MultiCharts 实战练习

建议按顺序完成，每个练习都保存代码、参数、交易列表和绩效概要。

1. **均线交叉**：日线收盘价上穿 20 日均线做多，下穿 20 日均线平仓。
2. **时间区间突破**：统计 09:31—09:45 的最高价和最低价，下一根 K 线开始允许突破进场。
3. **每日一次交易**：加入 `TradedToday` 状态，避免平仓后同日重复进场。
4. **收盘强平**：在最后允许交易时间前发出平仓指令，核对实际成交时间。
5. **夜盘交易日**：为含夜盘品种定义交易日首棒，验证周一和节假日后的首棒。
6. **稳健性检查**：用不同手续费、滑价、数据周期和测试区间重复回测。

每次练习先写“策略规则”，再写代码；回测后记录“预期行为”和“实际行为”的差异。
