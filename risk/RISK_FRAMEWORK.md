# 个人量化研究风险框架

这是学习阶段的框架草案，应根据市场、资金、经验和监管要求持续调整。

## 基本原则

- 先定义最大可接受损失，再讨论收益目标。
- 单一策略、标的和风险因子都要设集中度上限。
- 杠杆会同时放大模型错误、执行错误和流动性风险。
- 回测不能证明安全，只能帮助识别部分历史风险。

## 每个策略必须回答

- 最坏历史回撤是多少？压力情景下可能扩大到多少？
- 收益是否依赖少数日期、标的或参数？
- 流动性下降或点差扩大时会怎样？
- 数据延迟、重复下单或交易接口中断时如何停机？
- 哪些指标触发减仓、暂停和人工检查？

## 上线前检查

- [ ] 无前视偏差和明显数据泄漏
- [ ] 包含合理且偏保守的费用与滑点
- [ ] 完成样本外和压力测试
- [ ] 明确仓位上限、损失上限和停机条件
- [ ] 可核对信号、订单、成交和持仓
- [ ] 先运行模拟盘，再考虑小规模实盘
