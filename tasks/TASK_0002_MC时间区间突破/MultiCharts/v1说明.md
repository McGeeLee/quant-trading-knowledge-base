## 输入参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `TestStartDate` | 1160621 | 回测逻辑启用日期 |
| `TestEndDate` | 1160630 | 回测逻辑结束日期 |
| `Time1` | 0931 | 区间统计开始时间 |
| `Time2` | 0945 | 区间统计结束时间 |
| `UpValue` | 1.0 | 多头突破加点 |
| `DnValue` | 1.0 | 空头突破减点 |
| `SP` | 30 | 停利点数 |
| `SL` | 50 | 停损点数 |
| `StopTime` | 1100 | 禁止进场时间起点 |
| `CloseTime` | 1458 | 发出收盘平仓指令的 K 棒时间 |

## 为什么最快是 09:46

代码先在 09:45 K 棒中完成最后一次区间更新，然后立即令 `RangeReady = True`。同一轮计算继续执行进场条件，并提交：

```text
next bar at RangeHigh + UpValue stop
next bar at RangeLow - DnValue stop
```

因此 09:45 发出的订单作用于下一根 09:46 K 棒。如果把判断写成 `Time > Time2`，第一次满足条件会推迟到 09:46，`next bar` 最快只能在 09:47 成交。

## 为什么使用 CalcTime(StopTime, -1)

目标是让 11:00 K 棒不能进场。由于订单作用于下一根 K 棒，不能只检查当前时间 `< 1100`，否则 10:59 仍可能发出作用于 11:00 的订单。

```text
Time < CalcTime(1100, -1)
```

在 1 分钟图上，只有 10:59 之前的计算轮次能够继续挂下一根订单；最后一笔可能成交在 10:59，11:00 不再进场。

## 每天只交易一次

- 新交易日记录 `TradesAtDayStart = TotalTrades`，并把 `TradedToday` 重置为 `False`。
- 当天一旦出现持仓，或已完成交易数超过日初值，就把 `TradedToday` 设为 `True`。
- 进场条件要求 `TradedToday = False`，因此即使当天较早出场，也不会再次进场。

## 停利和停损单位

`SP`、`SL` 按价格点数输入。`SetProfitTarget` 和 `SetStopLoss` 接收金额，因此代码乘以 `BigPointValue`，并通过 `SetStopContract` 按每手计算。

## v1 限制

- 以 `Date` 变化作为每日重置依据，只适用于本次日盘基本型；晚上 21:00 开始的夜盘会跨日，需要另行定义交易日边界。
- 连续合约涉及换月与价格拼接，报告结果不能直接等同于单一可交易合约的实盘表现。
- 同一分钟内若最高价和最低价同时越过两侧触发价，结果可能受 MultiCharts 的 K 棒内路径假设、Bar Magnifier 或精细回测设置影响。
