# TASK_0002 MultiCharts v2 说明

## 版本结论

v2 保留 v1 的进出场逻辑，只移除代码内的测试起止日期。以后更换回测日期时，直接在 MultiCharts 面板或图表数据范围中调整，不必修改并重新编译策略代码。

## 运行环境

| 设置项 | 数值 |
|---|---|
| 软件 | MultiCharts 64 位版 |
| 商品 | `CFFEX.IF.HOT`（IF 连续月） |
| 周期 | 1 分钟 |
| 交易时段 | 日盘 |
| 每次数量 | 1 手 |
| 手续费 | 0（本次验收设置） |
| 滑点 | 0（本次验收设置） |
| 测试日期 | 由 MultiCharts 面板或图表数据范围控制 |

## 输入参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `Time1` | 0931 | 区间统计开始时间 |
| `Time2` | 0945 | 区间统计结束时间 |
| `UpValue` | 1.0 | 多头突破加点 |
| `DnValue` | 1.0 | 空头突破减点 |
| `SP` | 30 | 停利点数 |
| `SL` | 50 | 停损点数 |
| `StopTime` | 1100 | 禁止进场时间起点 |
| `CloseTime` | 1458 | 发出收盘平仓指令的 K 棒时间 |

## 与 v1 的差异

v1 有以下两个输入参数和两条进场过滤条件：

```text
TestStartDate
TestEndDate
```

v2 将它们全部移除。策略只对图表中已加载并由面板允许测试的数据执行，切换日期时无需手动修改 PowerLanguage 代码。

## 09:46 与 11:00 逻辑不变

- 09:45 K 棒完成区间统计，并在同一轮提交 `next bar` 停止单，最快 09:46 成交。
- 进场条件继续使用 `Time < CalcTime(StopTime, -1)`，因此 11:00 这根 K 棒不允许进场。

## 内置停利停损的同棒歧义

代码继续使用：

```text
SetStopContract;
SetProfitTarget(SP * BigPointValue);
SetStopLoss(SL * BigPointValue);
```

这类内置停利、停损可能在进场的同一根 K 棒触发。只有 1 分钟 OHLC 时，回测引擎无法必然知道该分钟内部的真实先后路径。

例如，策略在 7000 买进，而同一分钟最高价为 7080。若真实行情先到 7080、后回落到 7000 才进场，7080 实际发生在进场前，不应视为进场后的停利；但仅凭该分钟的开高低收无法还原这个先后顺序。

因此，遇到同棒进出场或高波动商品时应：

1. 单独标记并检查这些交易。
2. 使用更细粒度数据、Bar Magnifier 或目标环境提供的 K 棒内回测设置复核。
3. 在交易列表中核对进场、出场时间及成交价，不把 1 分钟粗粒度结果直接当成精确成交路径。

## v2 仍然是日盘版本

本版继续以 `Date <> Date[1]` 重置每日变量，只适合当前 IF 日盘基本型。夜盘会跨自然日，不能直接沿用这一重置方式；夜盘版本应按真正的交易日首棒或 Session 边界重置。
