## 目录说明

- `tasks/`：具体交易任务。任务内保存原始资料、任务说明、知识总结和不同软件的实现。
- `tools/`：不占正式任务编号的扫描器和辅助脚本。
- `归档/`：书籍与课程、原始参考文档、平台知识和历史规范。

## 基本规则

1. 新需求先建立任务，再选择需要实现的软件。
2. 同一任务的不同版本不得互相覆盖。
3. 每份代码必须有同版本说明文件，记录面板设置、策略行为、验收结果和版本差异。
4. 原始资料不得修改；修订结论写入任务说明或版本说明。
5. 回测结果不得表述为实盘收益，回测代码不得误入实盘运行。

学习材料见[学习资料索引](归档/学习资料/README.md)，历史代码规范见[代码要求](归档/规范/代码要求.md)。
