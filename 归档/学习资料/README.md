# 量化学习资料索引

本目录归档书籍封面、课程入口和学习建议。图片仅用于识别资料，不包含书籍电子版正文。

## 建议学习顺序

1. 阅读两本 MultiCharts 主教材，先熟悉平台、PowerLanguage 和策略运行流程。
2. 学习策略星学院课程目录中的前两个单元：`MultiCharts-入门课程`、`【MultiCharts-从入门到精通】`。
3. 学习指定补充单元 713 和 714。
4. 阅读《交易策略评估与最佳化》，学习策略测试、优化陷阱与推进分析。
5. 有余力时再阅读两本 AI/量化补充读物。
6. 当前阶段跳过期权相关课程。
