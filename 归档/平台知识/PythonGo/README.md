# PythonGo 平台知识

## 平台定位

[PythonGo 官方文档](https://infinitrader.quantdo.com.cn/pythongo/)将其定义为基于无限易（InfiniTrader）的 Python 策略交易引擎。它可以用 Python 编写交易策略，并结合无限易的 C++ 引擎进行历史数据回测和实盘交易。

官方列出的主要特点包括：

- 交易流程和工作机制较简明。
- 对实时回报进行分类管理。
- 采用 C++ + Python 技术架构。
- 提供策略界面，便于查看运行结果。

## 建议学习路径

按官方文档目录依次学习：

1. 安装 PythonGo 运行环境。
2. 完成操作入门。
3. 学习策略开发与策略基础。
4. 查询函数定义和类型定义。
5. 学习指标转换与策略进阶。
6. 阅读风险提示和程序化交易框架说明。

## 在知识库中的使用规则

- PythonGo 的具体策略应放在对应任务目录的 `PythonGo/` 子目录中，不直接放在本页。
- 每个策略版本仍使用 `v1`、`v2` 等独立代码和说明文件，不覆盖旧版本。
- 回测代码与实盘代码必须明确区分；进入实盘前重新检查合约、方向、手数、重复下单、交易时段和退出条件。
- 不在知识库中保存交易账号、密码、接口密钥或本地登录配置。
